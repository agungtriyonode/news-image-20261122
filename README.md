# World News — Sunday, 22 November 2026

A newspaper front page that sums up the world's news of Sunday, 22 November 2026 in one image: COP31 in Antalya nearing a final deal after talks ran past their Friday deadline and through Saturday night, India passing 520 for their highest Test total ever in New Zealand (Pant's century in Wellington), cricketer Yuzvendra Chahal joining the BJP, and Britain and the Netherlands pledging sustained support for Ukraine. Built for the [make.fun bounty "Sum up 22 November's world news in one image"](https://make.fun/bounty/sum-up-22-november-20261122-0700).

## Run

Node 22. The program copies `entry.png` to the output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes the same bytes on every run, with no network access. The image is 1024×1024 and under 1 MiB.
